# crackme-series

숭실대학교 해킹 동아리 ASC 2026-2학기 개인 프로젝트로 만든, 리버싱 입문자를 위한 난이도별 크랙미 시리즈입니다.

- 플랫폼: Linux x86-64 ELF
- 목표: 올바른 입력을 찾아 `Correct!!`를 출력시키기

## 레벨

| 레벨 | 주제 | 상태 |
|---|---|---|
| Lv1 | 하드코딩된 키와 문자열 비교 | 완료 |
| Lv2 | XOR·연산 기반 검증 | 예정 |
| Lv3 | 다중 조건 수식 | 예정 |
| Lv4 | 수식 풀이 도구 회피 | 예정 |
| Lv5 | 안티 디버깅 | 예정 |
| Lv6 | 제어 흐름 난독화 / 패킹 | 예정 |

## 실행 방법

```bash
cd lv1
./bin/lv1
```

직접 빌드하려면 각 레벨 폴더에서 `make`를 실행합니다.

## 폴더 구성

```
lvN/
  src/        소스 코드 (정답 포함 주의)
  bin/        배포용 실행 파일
  Makefile    빌드 옵션
  writeup.md  제작자 풀이
```

먼저 `bin/`의 실행 파일만으로 풀어본 뒤에 `src/`와 `writeup.md`를 확인하는 것을 권장합니다.
